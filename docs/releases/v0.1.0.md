# mojo-glob v0.1.0

## What it does
Shell-style wildcards for Mojo: `fnmatch` and `glob` identical to Python 3.14 on POSIX.

## Highlights
- Compiled `Pattern`: 16 to 123 ns per match, against 168 to 245 ns in Python.
- Recursive `**`, `root_dir`, `include_hidden`, Unicode-aware `?` and classes.

## Changes
- First release.

## Verified
- `scripts/ci.sh` PASS on Mojo 1.2.0 and 1.3.0.dev2026110305: fnmatch matrix (42 patterns x 37 names, plus invalid-UTF-8 names) and 132 glob results byte-identical with Python 3.14.8, each twice; 6/6 mutants.

## Known limits
- POSIX only (no Windows case folding or drive letters). `fnmatch` recompiles class patterns per call. No `translate()` to a regex.

## Upgrade / run
- Add `mojo-glob`, then `from glob import glob`. Try `examples/quickstart.mojo`.
